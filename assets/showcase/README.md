# Four source-review illustrations

These small diagrams illustrate documented synthetic scenarios; they are not
screen recordings, benchmark charts or evidence of production execution.

Each project has an editable SVG layout, a three-frame GIF, a static PNG and a
600px vertical mobile variant. The profile uses native `picture` sources for
mobile and reduced-motion preferences; native text carries the explanation too.
Trading uses blue/amber accents, backend uses teal/violet. No external statistics
widget, tracker or runtime script is required. `manifest.json` records dimensions
and animation sizes. Source/tests/release links remain ordinary GitHub links.
